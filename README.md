# 영어 튜터 (EnglishTutor)

Claude AI가 1:1로 영어를 가르쳐 주는 Windows 데스크톱 앱입니다. 한국인 성인 초급(A1)부터 중상급(B2)까지, 회화·영작·독해·어휘를 실제로 쓸 수 있게 하는 데 집중해요. 개인이 만든 무료 앱이에요.

- **통합 과정 3단계**: 표현 → 문법 → 읽기 → 상황극 → 쓰기 → 정리로 이어지는 레슨, '다음 ▶' 버튼으로 바로 진행
- **말하기·듣기**: 🎤로 영어로 말하면 받아 적고, 🔊로 원어민 목소리로 읽어 줘요 (음성은 PC 안에서 처리, 무료)
- **회화 상황극**: 카페, 식당, 여행 등 장면 카드와 함께 역할극, 자연스러운 표현으로 고쳐 주기
- **영작 첨삭**: 고친 곳을 표시하고, 더 자연스러운 문장과 이유를 알려 줘요
- **독해 3단계**: 짧은 글부터 원문 같은 기사·에세이까지, 긴 문장 끊어 읽기(구문), 문장별 듣기, 읽기 속도(WPM) 기록
- **단어장과 복습**: 단어별 간격 반복, 오답노트
- **구글 계정 동기화(선택)**: 여러 PC에서 진도와 대화를 이어 가기

## 받기

**[최신 버전 내려받기 (EnglishTutor.exe)](https://github.com/Leopard7711/EnglishTutor-releases/releases/latest/download/EnglishTutor.exe)**

- Windows 10/11 (64비트). 설치 없이 exe 하나로 실행돼요.
- 읽어 주기·받아쓰기 모델(약 270MB)은 처음 쓸 때 한 번만 내려받아요.
- 새 버전이 나오면 앱이 켜질 때 알아서 업데이트해요.
- **이 페이지(github.com/Leopard7711/EnglishTutor-releases)에서만 받으세요.** 다른 곳에 올라온 파일은 변조됐을 수 있어요.

### "Windows의 PC 보호" 창이 뜨면

코드 서명 인증서가 없는 개인 앱이라 처음 실행할 때 Windows가 경고를 띄워요.
**추가 정보** → **실행**을 누르면 됩니다. 백신이 막으면 이 페이지에서 받은 파일인지 확인한 뒤 예외로 허용해 주세요.

## 처음 시작: Anthropic API 키 넣기

이 앱은 AI 사용료를 **본인의 Anthropic 계정에서 직접** 내는 방식이에요(개발자에게 가는 돈은 없어요).

1. https://console.anthropic.com 에 가입합니다.
2. **Billing**에서 결제 수단을 등록하고 크레딧을 충전합니다.
3. **API Keys** → **Create Key**로 키(`sk-ant-…`)를 만들어 복사합니다.
4. 앱을 처음 켜면 나오는 창에 붙여 넣으면 끝. 키는 이 PC에만 저장돼요.

## 비용은 얼마나?

앱 아래 상태줄에 이번 세션과 누적 비용(추정)이 늘 표시돼요. 설정에서 모델을 바꿀 수 있어요.

| 모델 | 특징 | 대략적인 비용 |
|---|---|---|
| Opus (기본) | 가장 섬세한 설명과 뉘앙스 | 공부 1시간에 약 $3 |
| Sonnet | 대부분의 레슨에 충분 | 약 절반 |
| Haiku | 회화·연습·단어 복습에 추천 | 훨씬 저렴 |

실제 비용은 대화 길이와 양에 따라 달라요. 영어 학습은 Haiku로도 대부분 충분하니, 비용이 걱정되면 설정에서 Haiku를 골라 보세요.
